# StealthPointer

StealthPointer, except it's open source, distributed for personal and non-commercial purposes under the original license.

## Requirements

- macOS 12.4 or later.
- An Apple Silicon or Intel Mac.
- Xcode & macOS SDK.

## Build

Open `StealthPointer.xcodeproj`, select the **StealthPointer** scheme, and build or run the app.

```sh
xcodebuild -project StealthPointer.xcodeproj \
  -scheme StealthPointer -configuration Release \
  -derivedDataPath build
```
